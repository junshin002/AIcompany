# AI社員オフィス / Company OS

0円運用を優先した、GitHub Pages対応の「AI社員オフィス」です。

## できること

- 秘書・経営企画を司令塔にした全社チャット
- 営業 / 企画 / 人事 / SE / デザイン / 総務 / 経理への直接指示
- 全体指示から、キーワードに応じて最大5部署へ自動配分
- 部署ごとに役割・専門領域を持つシステムプロンプト
- 案件・タスク・成果物・活動ログのローカル管理
- 成果物のダウンロード（Markdown / CSV / JSON / HTML）
- JSONバックアップ
- 会社設定とAIモデル選択
- ピクセル風のトップビュー・オフィス

## 0円構成

この版は外部AI APIを使いません。WebLLMを使ってWebGPU対応ブラウザの中でLLMを動かします。そのためAPIキーやサーバー料金は不要です。

### 推奨環境

- 最新のGoogle ChromeまたはMicrosoft Edge
- WebGPUが有効なPC
- 初回モデルダウンロード用のインターネット接続

標準モデルは `Llama-3.2-1B-Instruct-q4f16_1-MLC` です。端末性能に応じて設定から変更できます。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作る
2. このZIPの中身をリポジトリ直下へ配置
3. `Settings` → `Pages` → `Deploy from a branch`
4. branch=`main` / folder=`/(root)` を選択
5. Save

このプロジェクトはビルド不要の静的サイトです。

## データについて

案件、タスク、成果物、会話、活動ログはブラウザの `localStorage` に保存します。別PC・別ブラウザとは同期されません。定期的に「データをバックアップ」を使用してください。

## 会社レベルで使う場合の注意

これは「AIを使った業務支援用の仮想会社OS」です。現時点では会計ソフトや人事DB、メール、クラウドストレージ等の外部サービスとは接続していません。またGitHub Pagesは静的ホスティングであり、商用SaaSのホスティング用途には制限があります。個人用の業務効率化ツールとして使い、機密情報や認証情報、決済情報を入力しない運用を推奨します。
